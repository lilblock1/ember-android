## Justification

Ember is an unofficial Android application for legitimately owned Java Edition. We
request authorization for Microsoft account sign-in, Xbox Live/XSTS token exchanges,
Minecraft Services authentication, Java Edition entitlement verification and profile
retrieval. Installation and gameplay remain disabled until valid access is verified;
unknown responses fail closed. The app uses system-browser authorization code flow
with PKCE and Android Keystore-backed encrypted credentials. It does not collect
Microsoft passwords or include proprietary game files. Android ARM64 execution and
rendering compatibility are experimental, and the real client has not yet launched.

## Other information

techniques and any offline-use restrictions. No existing launcher client ID is reused.
Access approval and applicable licensing permissions are separate requirements.
