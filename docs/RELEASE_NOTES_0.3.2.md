# Ember 0.3.2 research

The original array-cast adapter now passes on S25+ and the real client proceeds past
that ART verifier failure. New original read-only archive and Android process/GC bridges
let it enter normal argument parsing and authenticated startup. ARM64 native memory
support implements owned allocation, direct/typed views, reallocation, checked access,
copy/set, standard UTF-8 and explicit freeing.

The authenticated 1.20.4 client now reaches GLFW backend initialization. Its fresh private
crash report identifies org.lwjgl.opengl.GL as missing. A new opt-in device collector
exports only structural error facts after client process termination. Actual session
values and raw authenticated crash reports stay on the phone.

No main menu, world, save or game rendering/input result is claimed. Desktop OpenGL
translation, substantial LWJGL functionality and full asset installation remain absent.
This is managed ART execution research plus original ARM64 platform components, not a
completed native port. No game binaries, translated game files, JVM or Pojav code are
included in artifacts. See CLIENT_STARTUP.md and VALIDATION.md for exact evidence.
